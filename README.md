# G-Rides

G-Rides is a car rental application built with React Native, Expo, and TypeScript.

## Getting started

```bash
npm install
npm start
```

From the Expo development server, open the app in Expo Go or launch an Android/iOS simulator.

## Project structure

```text
src/
├── components/  # Reusable UI components
├── constants/   # Application constants
├── contexts/    # React context providers
├── hooks/       # Reusable React hooks
├── navigation/  # Navigation configuration
├── query/       # Server-state and query configuration
├── screens/     # Application screens
├── services/    # APIs and external integrations
├── theme/       # Colors, spacing, typography, and styles
├── types/       # Shared TypeScript types
└── utils/       # Shared utility functions
```

## Available commands

```bash
npm start       # Start the Expo development server
npm run android # Open on Android
npm run ios     # Open on iOS (requires macOS)
npm run web     # Open in a web browser
```
